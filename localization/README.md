# TR / EN

Bölüm başlığı, giriş, etkileşim etiketi ve diyalog çiftleri `data/levels.json` içinde `[Türkçe, English]` sırasındadır. Arayüz çiftleri `State.text` üzerinden seçilir. Hayvan ve dünya kimlikleri çevrilmez. Dil tercihi cihaz kaydında korunur. Diyalog geçmişi iki dili de saklar; geçmiş dil değişiminden sonra seçilen dilde okunur.
