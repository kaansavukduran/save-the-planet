# Fragaria loading references

These are source copies, not newly designed or approved final logos. Do not infer approval from filenames.

* `fragaria-strawberry-reference.jpg`: exact copy of `assets/source/aionia-references/Fragaria_Cilek_Gorsel_Referansi.jpg`, official reference folder file `1dU0VP3r8Jayjpct5pdTHzsvinQKw_S4O`. Used by the web loading screen.
* `fragaria-strawberry-reference.png`: unchanged Drive file `1r_DKu4j925MJzam3KPadk3_mZvib77cM`, downloaded and visually inspected on 2026-11-12. Same strawberry design, provided PNG copy; used because Godot's native boot splash accepts PNG only. No pixel edits. Final logo status remains pending under 00_BAŞLA.
* Loading composition inspected from Drive `1rEV10lOPmxDb9QctaRzRpauIVbmdE9et` (`fragaria_yukleme_referansi.jpg`), reinforced by AIONIA v1.4 sections 18–19. Demo 60% and version are not reused.

`Press Start 2P` by CodeMan38 is licensed under SIL OFL 1.1; the original font and license were downloaded from https://github.com/google/fonts/tree/main/ofl/pressstart2p. Used only for branded decorative loading typography. Normal UI requests an OS system font; the web engine falls back to the bundled readable font where browser sandboxing prevents local font access.

Native boot uses a static strawberry on black, then the game UI; it has no genuine engine bootstrap progress hook. Web has the full named brand and real download callback. These platform differences are explicit, not claimed as identical.
